# This section is dedicated to why and how this blog works

## About the why

I'll start by addressing some concerns I've already received:

**Why build a blog with egui?**
- "It's not the right tool"
- "Better tools exist like Hugo or [insert your favorite static site builder here]"
- "It's not as accessible as other options"

Well, first of all, I'm making this blog not because I love writing content for others to read. It's mostly about having fun, learning new things, and improving my egui skills.
I don't really care whether it's the "right" or "wrong" approach—I'm not paid to do this, so I'll do it the way I want.
Another reason is that I'm planning to include a lot of interactive elements in this blog that would have been difficult to implement with other tools.
